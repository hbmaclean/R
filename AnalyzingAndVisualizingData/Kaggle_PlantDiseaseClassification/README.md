# Kaggle Plant Disease Classification

I chose the [Plant Disease Classification](https://www.kaggle.com/datasets/turakut/plant-disease-classification/) dataset from many at Kaggle, drawn again by my hobbyist interest in plants. It also lists the work of others, whose accuracy results provide some reference point.

The goals of this project:

 * Continue learning, R and data science
 * Improve upon my testing and reporting framework from earlier projects
 * Pull from a source other than [UCI](https://archive.ics.uci.edu/datasets)
 * Achieve an accuracy comparable to what is listed (75-85%)
